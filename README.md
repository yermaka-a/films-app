# films-app

## To run
1. download the repository by the link: [this repo](https://github.com/yermaka-a/films-app)
2. use the following command in the repository folder in cmd | bash:
    - `yarn install`
3. edit .env.default file or use my parameters and write this in your cmd to start the project in dev mode:
    - `yarn dev --mode default`
